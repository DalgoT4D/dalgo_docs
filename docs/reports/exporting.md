# Exporting and deleting

## Exporting a report as PDF

1. Open the report you want to export.
2. Select the **download icon** in the top-right corner.
3. The report downloads as a PDF file to your device.

## Sending a report as a PDF email

Send the report as a PDF attachment directly to one or more email addresses — useful for stakeholders who aren't Dalgo users.

1. From the **Reports** list, select the **⋯ menu** on the report row and choose **Email PDF**. Alternatively, open the report and select the **mail icon** in the top-right corner.
2. Enter a subject line (pre-filled with the report title).
3. Enter recipient email addresses, separated by commas or semicolons.
4. Select **SEND REPORT**.

The report is exported as a PDF and delivered as an email attachment. You can send to up to 10 recipients at once.

:::note
**Email PDF** is only available to users with **Can Edit** access to the report.
:::

## Deleting a report

1. On the reports list, select the **⋯ menu** on the report row.
2. Select **Delete**.

:::warning
Deleting a report is permanent. The report and all its comments will be removed and cannot be recovered.
:::
