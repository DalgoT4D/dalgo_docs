# September 21, 2026

Dashboards are no longer just a wall of charts. You can now write properly formatted text on them and drop in images — so the numbers arrive with the context that explains them.

## Text and Images on Dashboards

The dashboard text block has been rebuilt with a real editor, and images can now sit on the canvas alongside your charts.

- **Formatting toolbar** — headings, bold, italic, lists, links, and left, centre, or right alignment.
- **Colours** — set text and highlight colours from a set of presets, or pick any custom colour you like.
- **Images** — upload a logo, a photo, or a programme map and place it anywhere on the dashboard.

## Free Trial and Onboarding Polish

- **Step backwards in walkthroughs** — the guided flows for connecting a source and building your first KPI now let you go back a step without losing what you've already typed.
- **Clearer setup progress** — the provisioning screen after signup reports where things stand more accurately.

## Fixes

- **Number charts** — the builder now checks that a metric is set before you save, on both the create and edit screens, instead of leaving you with an empty tile to puzzle over.
- **Display Name on number charts** — the Display Name field no longer appears when you're building a big number chart. It had no visible effect there, so it was only ever a distraction.
