# August 17, 2026

Adding a data source used to mean hunting for a service account key and decoding cryptic field names on your own. Not anymore — a new step-by-step wizard guides you through the whole thing, and Google Sheets just got a lot easier to connect.

## Guided source setup

Connecting a data source is now a three-step flow: pick your source, configure it with a built-in help panel right beside the form, then create the connection — all without leaving the page.

- **Source picker** — browse sources by type or search by name. The most popular ones appear as large cards at the top so you can get started quickly.
- **Inline help panel** — while you're filling in credentials, a panel on the right explains each field and shows sharing steps specific to that source. No more switching tabs to look things up.
- **Step-by-step progress** — a header tracks where you are (source → configure → connect) so you always know what's left.
- **One unified page** — the three separate Connections, Sources, and Warehouse tabs are gone. Sources and their connections now appear together on one page, revealing progressively as you set things up.
- **Warehouse config moved to Settings** — your warehouse settings are now under Settings → Warehouse, keeping the Ingest page focused on data sources and connections.

## Google Sheets, simplified

No Google Cloud project? No problem.

- **Use Dalgo's service account** — share your sheet with Dalgo's email address and you're done. Dalgo pre-selects this option when you add a new Google Sheets source, so most users can connect without touching any credentials at all.

## Dashboard improvements

Dashboards are more flexible when you have multiple tabs.

- **Drag charts across tabs** — move a chart from one tab to another by dragging it onto the tab name. No need to delete and recreate.
- **Rich text editing** — the text element editor has been rebuilt with a more reliable toolbar. Bold, italic, links, and lists all work consistently.
- **Tab management** — creating, renaming, and reordering tabs is smoother, with cleaner visual feedback.

## Create metrics while building a KPI

You no longer need to leave the KPI wizard to create a new metric. If the metric you want doesn't exist yet, create it right there in the KPI setup step.

- **New metric inline** — a quick-create form appears inside the wizard. Fill in the details, save, and the KPI automatically picks it up.

## Column type control when ingesting from Google Sheets

When setting up a Google Sheets connection, you can now tell Dalgo exactly what type each column should be stored as — number, text, date, boolean, and so on.

- **Cast per column** — open a stream's advanced settings and pick the destination type for any column before the pipeline runs.
- **Works alongside sync settings** — cast configuration sits next to the existing stream-level sync options, so all your column settings are in one place.

## Fixes

- **Warehouse credentials** — updating warehouse settings (including SSL certificates) now reliably applies all changes. Previously, some credential fields could be silently ignored.
- **Duplicate dashboard** — refreshing the browser while saving a new dashboard no longer creates two copies.
- **Invitation resend** — resending a team invitation now works even when the original invitation record is no longer present.
