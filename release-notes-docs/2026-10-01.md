# October 1, 2026

Copilot is an experiment we're running to make your life easier: no SQL, just plain English. Ask a question and it digs through your warehouse, then offers to build the chart, dashboard, metric, KPI or report that goes with the answer.

## Copilot — Ask Your Data a Question

Copilot is a new page in the sidebar. You type a question in plain English; it looks at your warehouse tables, works out the query, runs it, and answers with the number and the table behind it.

- **Plain English in, real numbers out** — no SQL, no waiting on an engineer.
- **Follow-ups keep their place** — ask "and how does that compare to last month?" and Copilot knows what "that" refers to.
- **See the query** — every answer can be expanded to show the exact query that produced it, so you can check the logic or pass it to a colleague.
- **"Worth checking" notes** — when Copilot spots something about its own answer worth a second look — a missing filter, a suspicious zero — it says so above the result rather than letting you find out later.
- **Conversations are saved** — each chat is kept in a sidebar, titled automatically, so you can come back to a question you asked last week.

## Build Charts and Dashboards by Asking

Copilot doesn't only answer. It can make things, and hand you a link to open what it made.

- **Charts, metrics, and KPIs** — "build me a chart of surveys per district" gets you a real saved chart in your Charts list, not a throwaway image.
- **Dashboards** — ask for a new dashboard, or ask to add the chart it just made to one you already have. It checks which you'd prefer before doing either.
- **Reports** — snapshot a dashboard into a report from the conversation.
- **Questions about Dalgo itself** — ask how a feature works and Copilot reads the documentation to answer, so you don't have to go looking.

## You Approve Every Step

Copilot pauses and asks before it touches anything.

- **A plain-language receipt** — before running a query or creating a chart, you see what it's about to do in one line: *"Run this query on your data warehouse?"* or *"Create the chart 'Surveys by district' (bar) from prod.surveys?"* Approve it or cancel it.
- **Mask personal data before it leaves** — when a query would return columns that might hold personal information, the approval card lists them with tick boxes. Tick the sensitive ones and those values are scrambled before anything is sent on.
- **Read-only, always** — Copilot can only read from your warehouse. It cannot change, delete, or write data, by design rather than by policy.

## Getting Copilot Switched On

Copilot isn't open to everyone yet — it's still an experiment, so we're enabling it organisation by organisation. If you'd like it turned on for yours, say hello on <a href="https://discord.gg/d99RnSThT" target="_blank" rel="noopener noreferrer">Discord</a> or email <a href="mailto:support@dalgo.org">support@dalgo.org</a> and we'll get you set up.

Once it's enabled for your org, an admin finishes the setup under **Settings → Copilot**.

- **One switch** — turning it on confirms you're happy for questions and query results from your warehouse to be processed by an AI provider.
- **Teach it your vocabulary** — a Context box sits under the switch for the facts Copilot should know with every question: *"'SHG' means self-help group"*, *"Our fiscal year runs April–March"*, *"Monthly program data lives in prod.survey_responses"*. It makes a sizeable difference to how well the answers land.

## Transformations Now Run on dbt 1.10

dbt has been upgraded from 1.8 to 1.10, with the Postgres and BigQuery adapters that go with it.

- **Newer dbt, no action needed** — the upgrade happens on our side. Your transformation projects carry on as they are.
- **One less thing to set up** — dbt now installs alongside Dalgo itself rather than in a separate environment, so the "create the dbt env first" error that could block a transformation run is gone.
