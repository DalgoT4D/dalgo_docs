# September 25, 2026

The Data Quality section has left the building. It wasn't getting enough love inside Dalgo, and Elementary — the tool that powered it — is honestly happier when you run it yourself.

## Data Quality Section Retired

The Data Quality tab in the sidebar, along with the Elementary report setup screens, is gone. Your existing pipelines have been cleaned up too — the automated "send report" step no longer runs alongside your dbt jobs, so pipelines finish faster and with fewer moving parts.

- **Nothing to migrate** — if you weren't actively looking at the Data Quality page, you won't notice a thing.
- **Pipelines are lighter** — the extra Elementary step has been removed from every pipeline that had it.

## Running Elementary Reports Yourself

Elementary still works beautifully as a local CLI against your Dalgo warehouse. A quick recipe:

1. Install the CLI in a Python environment. Dalgo was running `elementary-data==0.22.0`, so pin to that version to stay compatible with the `_elementary` tables already in your warehouse: `pip install "elementary-data==0.22.0"` plus the adapter for your warehouse (for most Dalgo setups that's `"elementary-data[postgres]==0.22.0"`).
2. From your dbt project, run `dbt run-operation elementary.generate_elementary_cli_profile` and paste the output into `~/.dbt/profiles.yml`. Fill in any missing password or token.
3. Run `edr report`. Elementary reads your warehouse, builds a self-contained HTML dashboard, and opens it in your browser.

Full walkthrough with warehouse-specific notes: <a href="https://docs.elementary-data.com/oss/guides/generate-report-ui" target="_blank" rel="noopener noreferrer">Elementary's official guide</a>.
