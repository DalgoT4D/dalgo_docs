# July 14, 2026

Fewer roles, tidier navigation, and a brand new pivot table chart type.

## Simpler roles

We collapsed five roles into three — **Admin**, **Analyst**, and **Member** — so
it's easier to invite the right person for the job.

- **What each role sees** — the sidebar now shows only the sections a role can
  actually use. Members see Dashboards, Charts, Reports, KPIs, Impact and
  Alerts. Analysts also get the Data section (pipelines, ingest, transform,
  orchestrate, explore, data quality). Admins see everything, including Billing
  and User Management.
- **Who can delete what** — the person who created a dashboard, chart, report,
  metric, KPI, or alert can always delete their own work. Admins can delete
  anyone's.
- **A quick welcome tour** — the first time you sign in after this release, a
  short 3-step carousel walks you through the new role model. Dismiss it once
  and it stays dismissed.
- **Sharing across the org** — admins can now manage sharing on dashboards and
  reports even when someone else created them.

## Pivot tables

A new chart type for cross-tabulating data — rows, columns, and a value, laid
out the way you'd expect from a spreadsheet.

- Pick pivot table from the chart type list and drag in your rows, columns and
  aggregations.
- Works with the same filters, metrics and drill-downs as the other chart
  types.

## KPIs on shared dashboards

- **Public dashboards** — KPIs now render for people viewing a publicly shared
  dashboard, even when they aren't signed in.
- **Report snapshots** — KPIs also come along in report snapshots, so shared
  reports match what you see inside Dalgo.

## Alert emails match report emails

- **Alerts** — alert emails now use the same clean template as report emails,
  so everything in your inbox from Dalgo looks like it came from the same
  product.

## Metric selector redesign

- **Chart editor** — the metric picker is now an accordion, which makes it
  much easier to scan when you have a long list of saved metrics.

## Fixes

- **Calculated and saved metrics** — these now apply correctly to pie, number,
  and map charts (previously they were quietly ignored).
- **Deleting a user** — removing someone from your org no longer takes their
  dashboards, charts, metrics, KPIs, or alerts down with them. The content
  stays in the org.
- **Number formatting** — prefix and suffix (like ₹ or %) now work on numbers
  even when you haven't picked a formatting style.
- **Session handling** — when your session quietly expires in the background,
  Dalgo now refreshes it silently instead of bouncing you to the login screen.
- **Password reset link** — fixed an issue with the reset URL that could
  sometimes send you to a broken page.
